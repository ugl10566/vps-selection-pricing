## 先搞明白：你买的是"带宽"还是"流量"

这是新手最容易忽略、也最影响实际体验的一层。目前市面上便宜的 VPS 基本分两派：

**大带宽 + 限流量**：端口给得大（50M、100M 甚至 200M），但每月只送你固定流量，用完了限速。适合建站、跑接口这类"平时流量小、偶尔要冲高峰"的场景。

**小带宽 + 不限流量**：端口小（5M、10M、20M），但流量随便跑。适合持续上传下载、备份、挂机类用途。

雨云的云服务器两种都给，而且流量用完不是在半夜被清空——用不完的流量可以往次月叠加，超出后限速到 5M 左右，想恢复高速就单独买流量包。这个规则对流量波动大的站比"月底清零"那种友好得多。

判断方法很朴素：先去算你每天的真实出站流量，再顺手看一下流量包单价。流量长期吃满的，选不限流量款；只有偶尔爆的，选大带宽款。

## 国内机房和海外机房，差的不是价格是备案

这一点决定了你根本没法"随便买"。

国内机房（温州、宁波、深圳、十堰、宿迁、重庆这些）延迟低、带宽给得大方、还常带防御，但**凡是大陆机房，用来跑带域名的 HTTP 业务，域名必须先备案并过白**，否则域名访问不通。

海外机房（中国香港、日本东京、韩国首尔、美国洛杉矶、德国法兰克福）免备案，开机就能用，代价是线路质量参差——同样是"香港"，移动优化线路和普通线路晚高峰能差出一倍延迟。

## 按用途选配置，别按"性价比"选

### 建站 / 博客 / 小工具站

1 核 1G 到 2 核 2G 够用。真正要盯的是硬盘 IO 和线路稳定性，不是核数。静态站或者轻量 WordPress，2 核 2G + 30G SSD 是舒适区。今年想跑 Docker 面板、1Panel 这类东西，直接上 2 核 4G，别省那十几块钱。

需要免备案的话，香港是最省事的选择：雨云香港入门版 1 核 1G / 10M 双向是 28 元/月，标配版 2 核 2G / 20M 双向 35 元/月。

看的是回程线路，不是标称带宽。香港节点普遍走 CN2 / CMI 三网直连，日本东京有软银大带宽线，韩国首尔三网直连延迟约 60ms 内，还能选原生 IP 或住宅 IP——这两类 IP 解锁流媒体和部分海外服务的成功率明显更高，代价是贵：普通 IP 5 元/个/月，原生 IP 10 元/月，住宅 IP 25 元/月。

## 常见问题

**买了之后能升配吗？**
可以。云服务器支持随时扩容云盘、加购独立 IP；游戏云支持升级 / 降级、弹性变配，因为它是"配置决定价格"的模式，改动后按新配置计费。

**动态计费和固定计费选哪个？**
固定计费就是传统的按月租。动态计费把基础月租压低，然后按每天 CPU 超过 20% 的部分额外日结——相当于"用得多才多付"。适合白天跑、晚上闲置的用途，比如只在特定时段开的游戏服、偶尔跑的测试环境。全天候满负载的业务，固定计费更可预测。

**免费版是怎么回事？**
雨云论坛里有用户提到过"免费领取"入口，配置通常是 2 核 4G 一档，适合小规模联机试水。但这是限时活动性质的资源，不是长期在售套餐，能不能领到要看你打开官网时的实际状态，别当成常规方案来规划。

**香港和日本怎么选？**
香港胜在物理距离近，面向大陆用户延迟低，但带宽给得保守（20M~50M）。日本东京的软银大带宽线端口给到 100M 甚至 300M，适合需要搬运大流量的业务，代价是延迟比香港高一档。做跨境独立站、需要跑视频或者大文件分发的，日本更合适。
